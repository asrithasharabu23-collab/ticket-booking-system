# 🎬 Ticket Booking System

A movie ticket booking web application built using Python Flask, SQLite, HTML, CSS and JavaScript.

## 🚀 Features

- 🎬 View available movies
- 🎟️ Book movie tickets
- 💺 Select individual seats
- 💰 Calculate total ticket price
- 🚫 Prevent already-booked seats
- 🎉 Booking confirmation
- 📋 View booking history
- ❌ Cancel bookings
- 🔄 Available seats update automatically

## 🛠️ Technologies Used

- Python
- Flask
- Flask-SQLAlchemy
- SQLite
- HTML
- CSS
- JavaScript
